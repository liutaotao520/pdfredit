# 使用指南

## 导入与排序

支持“添加文件”、拖入文件、添加文件夹和 Windows 资源管理器右键入口。文件夹只扫描当前层，不递归读取子目录。PDF 和多页 TIFF 自动展开；移除列表中的页面不会删除源文件。

拖动左侧页面调整顺序，Ctrl 多选，也可以使用上移 / 下移或 Alt+↑ / Alt+↓。资源管理器传入的顺序可能与屏幕排序不同，请核对页序，或在列表右键选择按文件名排序。

## 排版

纸张、方向、留白与输出质量应用于所有页面。A3 为 297 × 420 mm。选中单页后可旋转、缩放和改变位置，也可以直接拖动预览内的内容。超出纸张的部分会被裁切。

“跟随原始尺寸”不加留白：PDF 使用原始物理尺寸，图片按 150 dpi 换算，页面最大 200 英寸。透明背景显示在白色纸张上，EXIF 方向会自动校正。

| 质量设置 | 图片输出 |
| --- | --- |
| 原始清晰度 | 保留解码像素并采用无损压缩，JPEG 输入导出后可能明显增大 |
| 高清 | 220 dpi，JPEG 质量 92 |
| 轻巧 | 144 dpi，JPEG 质量 82 |

这些选项不会主动放大小图，也不会将 PDF 页面整体转成低清图片。

## 水印

可选择文字或图片水印，设置不透明度、角度、位置和页码范围（如 `1,3-5`）。页码以最终排序为准。文字水印作为透明图像写入 PDF，便于在其他设备上显示中文，但不作为可搜索文字。

图片水印宽度可设为页面宽度的 5%–90%。勾选平铺后，密度 1–10 控制间距，数值越大数量越多；密度不会改变水印本身的大小。

## 导出与继续编辑

Ctrl+E 打开导出面板。选择文件名和保存文件夹，确认替换已有文件后才会覆盖。失败或取消会保留原文件；极少数最终写入失败会留下 `.pending` 恢复文件并显示位置，请先检查再处理。

Ctrl+S 保存 `.ipdf.json` 编辑方案。“更多 → 打开编辑方案”可恢复排序和设置。方案记录源文件绝对路径，**不包含源图片、PDF 或水印文件**，请一起备份；移动源文件后原路径会失效。

## 右键合并

“更多 → 安装右键「合并为 PDF」”注册当前用户入口，无需管理员权限，不修改默认打开方式。Windows 11 通常在“显示更多选项”中。传统静态菜单最多选择 100 个文件，更多文件请直接拖入软件。

卸载入口使用“更多 → 卸载右键菜单”。移动整个软件目录后需重新安装入口。命令行也可使用 `main.py --install-menu` / `main.py --uninstall-menu`；打包后对 EXE 使用相同参数。

## 命令行导出

```powershell
.\.venv\Scripts\python.exe -B -s main.py --export result.pdf --paper A3 --watermark-text "仅供参考" examples/01-sample.png examples/sample.pdf
.\.venv\Scripts\python.exe -B -s main.py --export tiled.pdf --watermark-image examples/watermark.png --watermark-scale 5 --watermark-tiled --watermark-density 10 examples/02-sample.png
```

命令行不覆盖已有文件，复杂的逐页位置调整请使用界面。导出回执在 `runtime/last-export.json`。

## 数据、退出与备份

日志和临时数据位于软件目录的 `runtime`，默认输出位于 `outputs`；软件目录需要写入权限。用户可在导出面板选择其他保存位置。系统字体缓存与资源管理器记录由 Windows 管理。

关闭主窗口即退出，没有后台服务；未保存编辑会弹出确认。备份时分别保留源码 / 依赖清单、完整发布目录，以及原始资料 / 输出 PDF / 编辑方案 / 水印文件。更新前先保存编辑并备份资料。
