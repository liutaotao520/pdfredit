# 使用指南

## 导入与排序

支持“添加文件”、拖入文件、添加文件夹和 Windows 资源管理器右键入口。文件夹只扫描当前层，不递归读取子目录。PDF 和多页 TIFF 自动展开；移除列表中的页面不会删除源文件。

拖动左侧页面调整顺序，Ctrl 多选，也可以使用上移 / 下移或 Alt+↑ / Alt+↓。资源管理器传入的顺序可能与屏幕排序不同，请核对页序，或在列表右键选择按文件名排序。

## 排版

纸张、方向、留白与输出质量应用于所有页面。A3 为 297 × 420 mm。选中单页后可旋转、缩放和改变位置，也可以直接拖动预览内的内容。超出纸张的部分会被裁切。

“跟随原始尺寸”不加留白：PDF 使用原始物理尺寸，图片按 150 dpi 换算，页面最大 200 英寸。透明背景显示在白色纸张上，EXIF 方向会自动校正。

| 质量设置 | 图片输出 |
| --- | --- |
| 原始清晰度 | 保留解码像素并采用无损压缩，JPEG 输入导出后可能明显增大 |
| 高清 | 220 dpi，JPEG 质量 92 |
| 轻巧 | 144 dpi，JPEG 质量 82 |

这些选项不会主动放大小图。普通 PDF 合并保持原生内容；修改嵌套内容流中的文字时采用下文说明的页面外观固定方式。

## 文字编辑与本地 OCR

1. 添加单页 PDF、多页 PDF、合并后的 PDF 或图片，选择要处理的页面。
2. 点击预览顶部“编辑文字”，或右侧“文字编辑”。“识别当前页”处理当前页，“识别全部”按列表顺序处理整份文档，可取消。
3. 有原生文字时直接提取；没有文字层时自动在本机 OCR。页面既有原生文字又有扫描图时，点击“补充识别页面中的图片文字”。中文 / 英文模型随完整软件包提供，不联网、不上传文件。
4. **直接点击页面上的文字**，在当前位置输入、选字、复制和粘贴。按 Enter 或点击空白处完成修改，Shift+Enter 换行，Esc 取消当前这次输入。输入中可用 Ctrl+Z / Ctrl+Y 撤销和重做；完成的一次输入作为一个操作记入页面撤销历史。
5. 右侧只调整字体、字号、颜色、粗体和斜体。拖动文字框上方的移动柄调整位置；尚未进入输入时也可直接拖动文字框。右侧文字列表用于定位，双击列表项可跳到页面内输入。
6. “添加文字”会直接打开页面上的输入框；“删除文字”删除选中块；“恢复原文”恢复原有块，或移除新增块。“撤销 / 重做”保留当前会话每页最近 30 次修改。
7. 翻页、切换设置、保存方案和导出前，会应用正在输入的内容。导出 PDF 生成新文件，或 Ctrl+S 保存包含文字编辑的方案以便下次继续。

文字内容始终在页面内修改。输入框会随窗口大小调整，较小的文字在输入时临时放大方便校对；旋转文字使用便于输入的水平编辑框，完成后按页面原有方向显示。字号仍以源页面的 pt 为单位，临时输入框大小不会改变导出的字号。每个文字块最多 12000 个字符，长内容可拆成多个块。

**字体**：支持微软雅黑、宋体、黑体、楷体、仿宋、Arial、Times New Roman、Courier New；“导入字体”可选本机 TTF / TTC。原文可能使用嵌入子集或本机没有的字体，修改后采用右侧选定字体，不能保证与原字体完全相同。修改文字的字体嵌入输出 PDF；缺字或限制嵌入的字体会给出提示，不会静默输出缺字框。自定义字体文件需与源资料一起保留。

**扫描件**：识别结果需要校对，识别置信度显示在文字设置中。未经修改的扫描文字仍保持原图外观，并增加可搜索文字层；修改时覆盖原文字区域后写入新字。“覆盖底色”用于匹配非白色纸张。复杂图片背景、手写、竖排、弯曲或低清文字不保证准确，覆盖区域可能留下痕迹。这是视觉编辑，不是安全涂黑 / 保密信息删除工具。

**排版边界**：按 PDF 文字对象或 OCR 行选择文字块，支持手动换行，不自动跨段落或跨页排版。普通 PDF 文字修改保留其余矢量内容；修改嵌套内容流或 PDF 中的 OCR 文字时，会将该页其余外观固定为最高 300 dpi、最长边 5000 像素，并补回已识别的可搜索文字。无法独立区分的重复引用文字会使用 OCR，以免编辑一处影响其他位置。其他页面不受影响。识别后若源文件被修改，会停止编辑导出并提示重新添加，防止替换错位置。

## 水印

可选择文字或图片水印，设置不透明度、角度、位置和页码范围（如 `1,3-5`）。页码以最终排序为准。文字水印作为透明图像写入 PDF，便于在其他设备上显示中文，但不作为可搜索文字。

图片水印宽度可设为页面宽度的 5%–90%。勾选平铺后，密度 1–10 控制间距，数值越大数量越多；密度不会改变水印本身的大小。

## 导出与继续编辑

Ctrl+E 打开导出面板。选择文件名和保存文件夹，确认替换已有文件后才会覆盖。失败或取消会保留原文件；极少数最终写入失败会留下 `.pending` 恢复文件并显示位置，请先检查再处理。

Ctrl+S 保存 `.ipdf.json` 编辑方案。“更多 → 打开编辑方案”可恢复识别结果、文字修改、排序和设置。方案记录源文件绝对路径，**不包含源图片、PDF、水印或自定义字体文件**，请一起备份；移动源文件后原路径会失效。

## 右键合并

“更多 → 安装右键「合并为 PDF」”注册当前用户入口，无需管理员权限，不修改默认打开方式。Windows 11 通常在“显示更多选项”中。传统静态菜单最多选择 100 个文件，更多文件请直接拖入软件。

卸载入口使用“更多 → 卸载右键菜单”。移动整个软件目录后需重新安装入口。命令行也可使用 `main.py --install-menu` / `main.py --uninstall-menu`；打包后对 EXE 使用相同参数。

## 命令行导出

```powershell
.\.venv\Scripts\python.exe -B -s main.py --export result.pdf --paper A3 --watermark-text "仅供参考" examples/01-sample.png examples/sample.pdf
.\.venv\Scripts\python.exe -B -s main.py --export tiled.pdf --watermark-image examples/watermark.png --watermark-scale 5 --watermark-tiled --watermark-density 10 examples/02-sample.png
```

可读取编辑方案或在本机识别扫描件：

```powershell
.\.venv\Scripts\python.exe -B -s main.py --export edited.pdf --project "合页方案.ipdf.json"
.\.venv\Scripts\python.exe -B -s main.py --export searchable.pdf --ocr scan.pdf
```

命令行不覆盖已有文件，复杂的逐页位置调整请使用界面。导出回执在 `runtime/last-export.json`。

## 数据、退出与备份

日志和临时数据位于软件目录的 `runtime`，默认输出位于 `outputs`；软件目录需要写入权限。用户可在导出面板选择其他保存位置。系统字体缓存与资源管理器记录由 Windows 管理。

关闭主窗口即退出，没有后台服务；未保存编辑会弹出确认。备份时分别保留源码 / 依赖清单、完整发布目录，以及原始资料 / 输出 PDF / 编辑方案 / 水印文件。更新前先保存编辑并备份资料。
