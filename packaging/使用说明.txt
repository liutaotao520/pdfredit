合页 1.3.4 · 图片与 PDF 合并

运行要求
Windows 10（版本 2004 或更新）/ Windows 11，64 位。
软件自带运行环境，不需要安装 Python，不需要联网。
安装或存放在有写入权限的本地普通文件夹中。

开始使用
1. 双击安装目录中的“合页.exe”。
2. 点击“添加文件”，也可以拖入图片、PDF 或文件夹。PDF 自动按页展开。
3. 左侧拖动排序，Ctrl 多选，上移/下移或 Alt+方向键调整。
4. “页面排版”设置纸张、留白、质量；选中页面后可旋转、缩放和移动内容（最低 5%）。纸张支持 A3（297 × 420 mm）、A4、A5 和 Letter。
5. “添加水印”支持自定义文字、图片、透明度、角度、位置和平铺。
选择“图片水印”后，“图片水印缩放”支持 5%–90%，按页面宽度计算。
勾选“平铺水印，覆盖整页”后，可调“平铺密度”1–10 级，数值越大越密。
3 级保持原有密度；图片和文字水印都可调整，大小与密度分别设置，密度可随编辑方案保存。
6. 点击“导出 PDF”，填写文件名并选择保存文件夹，核对页数、纸张和水印后再次点击“导出 PDF”。默认输出到软件目录的 outputs 文件夹。
退出、导出、覆盖确认和进度提示均使用主界面相同的黑白灰样式。
退出确认默认“继续编辑”；Esc 或回车保留当前编辑，点击“退出合页”才会放弃未保存的编辑。
导出中可点“取消导出”，等待当前操作结束；取消或失败会保留原有文件。

PDF 输入
可以混合添加多份 PDF 和多张图片，自由调整页序。
普通 PDF 的文字与矢量直接合并，保留原有清晰度和可搜索文字。
“跟随原始尺寸”保留 PDF 原始页面尺寸，或选择 A4 等统一纸张。
质量选项只压缩图片输入，不重新压缩 PDF 内容。扫描 PDF 不进行 OCR。
批注和表单的可见外观转为固定内容；不保留可交互表单、链接、附件、书签或签名效力。
需要打开密码的 PDF 请先解密并另存副本。单个 PDF 上限 2000 页。

右键合并
安装时可添加图片和 PDF 的右键菜单；也可在软件“更多”中安装或卸载。
资源管理器中选中文件 → 右键 → 合并为 PDF（合页）。
Windows 11 通常位于“显示更多选项”。传统右键入口最多选 100 个文件。
更多文件请拖入软件或添加文件夹；请在软件中核对最终页序。

保存编辑
Ctrl+S 保存编辑方案，之后在“更多 → 打开编辑方案”继续。
方案只保存源文件路径与设置，不会打包图片或 PDF。请同时保留源文件和水印图片。
水印可指定最终页码，例如 1,3-5；空白表示全部页。
移除列表中的页面不会删除源文件，输出也不能覆盖输入的图片或 PDF。

图片格式
支持 JPG/JPEG、PNG、BMP、WebP、TIFF、GIF、HEIC/HEIF、AVIF、
SVG、ICO、JPEG 2000、PCX、TGA、PPM/PGM/PBM、DDS、QOI 等。
多页 TIFF 自动展开；动态图片仅取首帧；SVG 栅格化。
PSD 仅读取兼容合成预览，不编辑图层；不支持 RAW、AI/EPS 或损坏图片。
“原始清晰度”使用无损图像压缩，文件可能较大；图片分享可选择“轻巧”。

停止、备份与卸载
停止：关闭窗口。有未保存的编辑时会提示；退出后没有常驻后台服务。
备份数据：原始图片、原始与输出 PDF、编辑方案和水印图片应单独备份。
备份软件：保留完整安装文件夹或安装包，不能只复制合页.exe。
日志与运行缓存保存在软件目录内的 runtime 文件夹。
卸载：Windows 应用列表中的“合页”，或运行目录内的 unins000.exe。
卸载器仅处理安装时写入的程序文件，导出的 PDF、用户方案和运行数据不主动删除。
第三方组件的许可文件位于 licenses 及 _internal 文件夹中。
